# DataForge 更新记录

## [2026-08-03] fix | 图谱结构化输出保守容错

- 图谱抽取在一次模型修复后会保守剔除无法可靠归类的实体、关系或属性及其依赖项，保留严格校验通过的事实；没有可安全三元组时仍不发布知识库。
- 任务详情区分 JSON/截断与实体属性约束失败，并在成功任务中展示已过滤项目的数量、名称和原因；缓存同步保留该告警，旧缓存格式继续兼容。
- 补充实体类型“编号”、非法属性值类型、无有效事实不发布、脱敏诊断和缓存复用回归。

## [2026-08-03] feature | 可复用文档库

- 文档管理新增源文档与文档库二级视图；可选择部分或全部源文档并命名创建文档库，成员保存具体来源版本，可显式编辑或更新到最新版本。
- 处理任务改为仅选择文档库；服务端展开其固定成员版本后创建独立知识任务，历史任务的来源快照不受文档库编辑或删除影响。
- 源文档仍被文档库引用时会拒绝删除并返回关联文档库；新增 API 与回归覆盖版本固定、任务创建和删除保护。

## [2026-08-03] enhancement | 固定流程开发区布局与待开发调试台

- 顶部工作区名称固定为“业务工作区”和“流程开发区”；流程开发区固定依次展示知识类型、标准流程、模板和 DataFlow 调试台。
- 标准流程恢复为三个内置流程的只读目录；模板页保持七个固定组合与全局默认模板切换。
- DataFlow 调试台作为最后一项页面明确标记“待开发”，未恢复 Studio、iframe、引擎、依赖或接口。

## [2026-08-03] enhancement | 保留 DataFlow 调试台目录与可切换默认模板

- “DataFlow 调试台”恢复为只读工作区名称，固定保留“知识类型”和“模板”两个页面；不恢复 Studio、iframe、DataFlow 引擎或通用编排。
- 知识类型目录恢复“多轮对话库”卡片，明确其当前没有内置模板、不能创建任务；文本知识库、问答知识库和知识图谱的标准流程名称不再带“医疗”前缀。
- 七个固定模板保留原有 ID：全量组合显示为“医疗模板”，其余模板按知识类型命名；每张卡片可将白名单模板设为全局持久默认项，任务向导随之自动预选。

## [2026-08-02] breaking | 下线 DataFlow，启用内置医疗标准模板

- 移除 DataFlow/Studio 运行入口、配置、CLI 参数、专用 API 与前端 `/studio` 页面；动态标准流程、草稿/版本和自定义知识类型不再对外提供。
- 新增 7 个固定医疗模板及 `GET /api/medical-templates`；默认模板同时创建文本知识库、问答知识库和知识图谱三项独立任务。
- 文本流程固定使用原生处理；问答与图谱继续使用共享 LLM。图谱失败只影响图谱任务。
- 启动清理会删除历史 DataFlow 调试状态、流程配置、任务和无引用派生产物，保留源文档、原生/LLM 结果与共享 Blob。

### 2026-07-30

- 重写项目说明，明确业务工作区与流程开发区的职责边界。
- 增加模块开发状态，区分现有原型、开发中能力和待开发模块。
- 补充关系库入库、向量或图索引、知识集合与应用访问的阶段规划。
- 增加 DataForge 数据加工全流程视觉图。
- 问答知识库新增内置标准流程，支持文档分片、Qwen3-32B 问答生成、严格格式校验、去重、发布和记录级溯源。
- 既有“知识图谱”类型新增样本文档验证发布、Qwen3-32B 三元组抽取和 SQLite 构图闭环；图谱知识库支持实体/关系筛选、一跳邻域及边证据溯源。
- 知识图谱发布升级为确定性 12 块后台验证，兼容 LightRAG 实体/关系字段，增加结构化缓存、临时错误重试、进度查询和已发布状态重启保护。
- 真实 Qwen3-32B 指南验收补充关系端点兼容标记、单响应关系预算、容量错误自适应降块和串行生产策略；整篇 80 块已生成 833 条记录及 824 节点/831 边图投影。
- 知识生产向导支持多选生成内容：一次提交会为每种内容创建独立、可溯源的知识库任务，并在服务端并发执行。
- 知识任务支持安全停止：等待任务立即结束，运行任务进入“正在停止”并在当前处理单元完成后停止；停止请求不会发布知识库、记录或图谱，批量任务彼此隔离。
